# 真机测试：持久栈数据段

用 d0 = LED Display（`Setting` 显示数值）验证三件事：

1. **栈是否跨「换代码」保留**（数据段方案的前提）
2. **`db` 栈与本地栈（`push/pop/poke/peek`）是否同一块内存**
3. `get`/`put` 按地址读写是否正常

按顺序操作，每次把上一段代码**覆盖**成下一段（不是新增）。

## 测试 A：数据跨代码保留

| 步骤 | 贴入 | 运行后 LED | 说明 |
|------|------|-----------|------|
| A1 | `1_store.ic` | `999` | 用 `put db` 写入 111/222/333 + 哨兵 |
| A2 | `2_read.ic` | 每秒循环 `111 → 222 → 333` | 若一直 `0`，说明栈没保留或 `get db` 读不到 |

**结论**：A2 显示 111/222/333 → 栈持久，数据段方案成立。

## 测试 B：`poke`（本地栈）→ `get db`（设备栈）

| 步骤 | 贴入 | 运行后 LED | 说明 |
|------|------|-----------|------|
| B1 | `3_poke.ic` | `777` | `poke 50 12345` 写本地栈 |
| B2 | `4_get.ic` | `12345` 或 `0` | `12345` = 同一块内存；`0` = 两块独立 |

## 测试 C：`put db`（设备栈）→ `peek`（本地栈）

| 步骤 | 贴入 | 运行后 LED | 说明 |
|------|------|-----------|------|
| C1 | `5_put.ic` | `888` | `put db 60 54321` 写设备栈 |
| C2 | `6_peek.ic` | `54321` 或 `0` | `54321` = 同一块内存；`0` = 两块独立 |
