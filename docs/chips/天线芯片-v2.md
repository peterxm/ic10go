# 交易天线双芯片 · v2 重写说明

原程序（v1）是手写 IC10：`housing「1」`=128 行、`housing「2」`=127 行，都顶满 128 上限。
v2 用 ic10go 的 `.icg` 编译器重写，**行为与原程序等价**（本地 VM 差分 write trace 完全一致，真机端到端验证通过）。

| 文件 | 说明 | 行数 |
|---|---|---|
| `housing2.icg` | housing「2」小型天线扫描（**完全结构化**：具名变量 / `for` / `func` / `db.stack[]`） | 115（+4 loader） |
| `housing1.structured.icg` | housing「1」中型天线锁定/审问（结构化 + regalloc 返回值合并） | **126** |

## v1 → v2 改进了什么

### 功能/正确性
1. **修掉重复 `alias` 歧义**：v1 里 `alias dish d0` → 后面又 `alias dish d1`，工具链按「后者生效」解析成 **空的 d1**；v2 直接绑定当前接线的 **d0**。
2. **上电时序/复位更明确**：`prepare` 显式复位 `BestContactFilter=-1 / Activate=0 / On=0`；角度无效时回 `recheck`（不复位）；信号丢失回 `prepare`；峰值触发前 `sleep 2`。

### 代码质量 / 可维护性
3. **chip2 完全结构化**：去掉所有 `sp`/`push`/`pop`/`label`/`goto`/`call/ret` 杂技，改成具名变量 + `for/if` + 辅助函数 `touchV()`/`estimate()`，用 `db.stack[base+…]` 直接寻址共享槽。
4. **chip1 结构化**：`coordinate()`（球面三角解算）、`waitloop()`、`track()` 成为真正的函数；内层循环替代跨调用 flag。
5. **接线/协议注释清楚**：每个端子、每个栈槽的用途都写在源码里。

### 编译/性能（ic10go 编译器配套改动）
6. **返回值 coalescing**：outlined 调用的返回值不再每条都多一条 `move`。
7. **循环感知溢出代价**：循环内/循环携带变量不再被轻易溢出（消灭了 `reacquire` 的栈溢出）。
8. **跨块 copy propagation**（`globalPropagate`）：消除 outlined 调用的形参搬运；带门控（不带该 pass 的结果更短时自动不用）。
9. **回归检查**：126 个仓库语料程序，变长 **0**、变短 4、相同 117。

## 共享协议（chip2 → chip1）
chip2 每个联系人类型 `t` 在**自己外壳栈**占 `MEMO=12` 槽：

| 偏移 | 含义 |
|---|---|
| `+1` | 当前信号 ID |
| `+2` | 握手位（chip1 置 1＝已取用；chip2 进/出新联系人时清 0） |
| `+3` / `+4` | 离开时 H / 进入时 H |
| `+5` / `+6` | 最小 V / 最大 V |
| `+7` / `+8` | 估计 H / 估计 V（输出） |

chip1 按旋钮 `base = 值×12` 读 `get(d5, base+1/+7/+8)`，并 `put(d5, base+2, 1)` 标记已取用。
（`d5` = chip2 的外壳；同一根数据电缆。也可改用网络 channel：chip1 `d5:0 ChannelN` ⇄ chip2 `db:0 ChannelN`。）

## 验证
- **VM 差分**：原程序 vs v2，1500 tick，write trace 完全一致（chip1 3372 次、chip2 3000 vs 2996（差 4＝被外提到 loader 的启动常量写））。
- **真机**（本地存档，接线见 `交易天线接线图.md`）：扳杆 → 锁定信号 → 中天线转向 → 峰值测量 → `InterrogationProgress 0→1` → `Activate=1` 放行 → `lever` 归零复位；可反复触发。
