## 关键连接说明
1. **唯一一根跨芯片电缆**：`housing「1」的 d5 螺丝` ⇄ `housing「2」的外壳`。
   - 共享栈协议：chip1 用 `get/put(d5, base+…)` 读 chip2 写在**自己栈**上的联系人数据。
   - 通道协议（已验证可行）：chip1 读 `d5:0 ChannelN`，chip2 写 `db.channel[0][N]`——同一根电缆上的同一网络。
2. **两台天线是各自独立的设备**：小天线（chip2，扫描/粗找）、中天线（chip1，精锁/审问）。
   当前接线里**小天线接在 housing「2」的 d0，中天线接在 housing「1」的 d0**。
3. **d0 不是唯一选择**：芯片端口与外壳螺丝一一对应；只要代码里的 `dish` 指向接天线的那个端子即可。
   （原程序曾用重复 `alias dish d0`/`d1` 造成歧义；重写版统一用 **d0**，与当前接线一致。）
4. **拨杆/旋钮**是人员操作输入：拨杆扳起 = 开始锁定/取消，旋钮选要锁定的联系人编号。

## 纯 VM 复现（不用接线）
```bash
ic10c run housing1.structured.icg --ticks 200 \
  --set d2.Open=1 --set d3.Setting=0 \
  --set d0.Idle=1 --set d0.SignalID=777 --set d0.SignalStrength=5
```
